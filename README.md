## 📖 Über dieses Repository

Dieses Repository enthält die **vollständige Dokumentation** der  
**zyklischen Kosmologie** – einer Theorie, die das Universum nicht als  
einmaligen Urknall beschreibt, sondern als **ewigen Zyklus** aus  
Expansion, Kontraktion und Wiedergeburt.

Im Zentrum stehen:

- **Resonanz** – die Grundschwingung des Kosmos (7.83 Hz)
- **Der Bund** – das Gedächtnis, das Zyklen überdauert
- **Die JOJO-Gleichung** – die mathematische Beschreibung der Oszillation
